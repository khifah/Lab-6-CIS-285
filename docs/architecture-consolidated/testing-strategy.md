## SQLite integration protocol

Use a fresh file database and managed receipt temporary directory per fixture, versioned migrations and foreign keys enabled on every connection. Verify schema constraints by attempting invalid writes, including duplicate source lines and operation keys. Use two independent connections with coordinated barriers, not timing-only sleeps, to exercise write reservation/commit contention. Verify bounded busy retry with unchanged operation key and no partial state after a simulated fault. Reopen the database after failure/commit to confirm durable observable state. Clean fixtures only inside their verified temporary paths.

Transactions may use BEGIN IMMEDIATE, but the chosen driver connection mode/commit API must be proven before adoption. Do not mix incompatible autocommit transitions or nested transactions. Verify local file protection assumptions separately from repository authorization; mocks cannot prove either.

## Acceptance and measurement

Run relevant Maven lifecycle commands only after an implementation task creates the project and JDK 21 is available. Record commands, versions, outcomes and failures; do not mark unrun tests passing. Manual Swing checks include optional/malformed receipt, invalid amount/split, pending/rejected visibility, non-member access, repeat click and persistence error feedback. UI checklists do not replace domain/transaction tests.

NFR-004/AC-011 require at least 90% of first-time participants to submit and identify review status unassisted. SC-001 requires 90% complete account access/group selection/expense submission in five minutes; SC-006 requires 90% identify who owes whom and review state. Record cohort size, tasks, time and success counts. SC-002/003/004 require all defined reconciliation/exclusion/filter test cases to succeed.

NFR-005/AC-012/SC-005 require at least 95% of measured balance and filtered-report displays within three seconds at specified data volume under documented normal conditions. Do not substitute database-query timing for displayed-result timing, or report whole-product success when reports are undelivered. Future network tests include latency and server/client rendering. Failed or incomplete evidence leaves the corresponding acceptance criterion open.
